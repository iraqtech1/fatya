# إصلاحات مراجعة فاتيا بتاريخ 6 تشرين الثاني 2026

يشمل هذا الإصدار تحديث Symfony إلى 7.4.23 وإزالة تنبيهات Composer الستة، وإضافة ترويسات منع التضمين وسياسة إحالة وHSTS على HTTPS. سياسة CSP الحالية تقيد التضمين والكائنات وbase فقط؛ ليست سياسة scripts كاملة لأن Vue يستخدم قوالب وقت التشغيل.

أصبحت قراءة `/api/state` تستعلم فقط عن حساب العميل وطلباته وتذاكره، أو تتجاوز هذه الجداول للزائر، ولا تقرأ الاستيرادات والمورّدين وسجل الإدارة. تبقى جميع عمليات الكتابة على الحالة الكاملة ضمن المعاملات والأقفال السابقة. إعادة تصميم كتابة الحالة وترقيم صفحات الإدارة تحتاج إصداراً مستقلاً واختبار ضغط.

التحديث الخلفي أصبح كل 15 ثانية بدل 3، مع توقف عندما تكون الصفحة مخفية وتحديث فوري عند العودة وتراجع حتى دقيقتين عند فشل الاتصال. عمليات المستخدم ما زالت تحدث الحالة مباشرة. لا يوجد ETag أو تحديث تفاضلي في هذا الإصدار.

إنشاء تذاكر الدعم محدود بخمس تذاكر لكل حساب خلال عشر دقائق. الطلب الزائد يعيد 429 وRetry-After دون إنشاء تذكرة، ولا يشترك العملاء المختلفون في حد IP واحد.

التحقق المحلي: فحص 120 ملف JavaScript و75 قالب Vue، جميع اختبارات الواجهة والبناء ناجحة، واختبارات Laravel على PHP 8.3.36 وSQLite مع ذاكرة 512MB نجحت بعدد 112 اختبار و717 تحقق. يشمل ذلك عزل الاستعلامات العامة، الترويسات على HTTP وHTTPS، وحد التذاكر بين حسابين. اختبارات API المتزامنة على MariaDB تُراجع في CI قبل النشر.

لم تُرقّ قاعدة بيانات الاستضافة ولم يُفعّل Qi أو ZainCash. تحتاج القاعدة خطة من الاستضافة واختبار استرجاع، ويحتاج الدفع بيانات المزود واختبارات تسوية. كذلك تبقى ملاحظات أحجام الحزم واعتماديات أدوات البناء التي لا توفر إصلاحاً متوافقاً جاهزاً للمتابعة. لا تعتبر هذه البنود محلولة بنشر هذا الإصدار.
