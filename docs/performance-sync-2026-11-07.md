# تحسين التحميل والمزامنة بتاريخ 7 تشرين الثاني 2026

فُصلت وحدة الإدارة وصفحات التعريف إلى ملفات تُحمّل عند فتحها. الكتالوج وواجهات العميل تحتفظ بالتصميم والتدفقات الحالية، وExcelJS يبقى مؤجلاً حتى الحاجة للاستيراد أو التصدير. الشاشات المؤجلة تعرض حالة تحميل وخيار إعادة محاولة واضح عند تعذر تنزيل الملف.

قياسات البناء المحلي للإنتاج قبل النقل وبعده بالبايتات غير المضغوطة، وليست قياساً لزمن شبكة هاتف:

| الملف | قبل | بعد |
| --- | ---: | ---: |
| JavaScript الأولي | 756597 | 481061 |
| CSS الأولي | نحو 343408 | 234223 |
| خط Cairo | 91664 بصيغة TTF | 34528 بصيغة WOFF2 |
| كل ملف شعار SVG | نحو 1163040 | نحو 731997 |

JavaScript الأولي المضغوط gzip أصبح 160853 بايت. أُعيد ترميز الصورة المضمنة في SVG إلى WebP lossless دون تغيير القياسات أو المسارات. قورنت الألوان المرئية وقناة الشفافية قبل الترميز وبعده وتطابقت؛ الألوان المخفية تماماً تحت alpha صفر لا تؤثر في الرسم.

التخزين المسبق للـPWA يقتصر على ملفات التشغيل وتبعياتها الثابتة والخط والهوية وأيقونات التثبيت: 12 عنواناً فريداً و2465364 بايت، نحو 2.35MiB. هذا العدد يشمل الأصول الإضافية التي لا تدخل كلها في حجم سطر Workbox المختصر. لا تُحمّل وحدة الإدارة أو ExcelJS أو كل صور الكتالوج عند التثبيت. الأصول العامة فقط تخزن عند زيارتها ضمن حدود الحجم والعمر، وصور الكتالوج تتحقق بالخلفية من تحديثاتها. لا تخزن API أو الجلسات أو الاستجابات الخاصة في Service Worker.

المزامنة تستخدم ETag للاستجابة النهائية بعد مصادقة المستخدم وتطبيق صلاحياته. يعاد 304 بلا جسم إذا لم تتغير الاستجابة؛ يتجاوز العميل تحليل JSON واستبدال القوائم عندها. لا يعتمد المدقق على revision فقط لأن انتهاء المخزون والإشعارات وتغير الأدوار قد يغير العرض مستقلاً عنه.

المدققات محفوظة بالذاكرة فقط، وتُمسح عند الطلبات المعدلة وتبديل الدور. القراءة التي تتزامن مع الدخول أو الخروج تعاد قبل قبول النتيجة كي لا تُطبق هوية قديمة. تظل الطلبات بعد نشاط المستخدم فورية، ويبقى التحديث الخلفي 15 ثانية مع التوقف عند إخفاء الصفحة والتراجع عند فشل الشبكة.

هذا التحسين يقلل النقل وإعادة بناء الواجهة عند ثبات البيانات؛ الخادم ما زال يحسب الاستجابة ويتحقق من الصلاحيات قبل 304. ليس بديلاً عن إعادة تصميم استعلامات الإدارة والحفظ واختبار الضغط.

التحقق: جميع اختبارات الواجهة، فحص 122 ملف JavaScript و77 قالب Vue، بناء الإنتاج مع ميزانيات آلية للحجم واكتمال ملفات التشغيل خارج الاتصال، و117 اختبار Laravel مع 747 تحقق على PHP 8.3.36 وSQLite. تشمل الحالات تغير البيانات والإشعارات دون revision، اختلاف حساب العميل وصلاحيات الموظف، وسحب جلسة المدير رغم إرسال ETag صحيح. تُستكمل اختبارات MariaDB وAPI في CI قبل النشر. جرى فحص المتجر ودخول الإدارة الليلي وصفحات التعريف بالمتصفح؛ فحص جهاز هاتف فعلي وفصل الشبكة على مستوى الجهاز ليسا ضمن هذه النتائج.
